# وكيل إنستغرام متعدد اللغات

**English · العربية · Русский · Türkçe · Polski · Čeština**

أربع عشرة مهارة لـ Claude تدير حساب إنستغرام بست لغات. مجانية، برخصة MIT، بلا تسجيل ولا مفتاح API.

هذه نسخة متعددة اللغات من مشروع [instagram-agent-skill](https://github.com/Jakeschincariol/instagram-agent-skill) للمطوّر Jake Schincariol. المهارات الثلاث عشرة الأصلية موجودة كما هي، وأضفنا:

- مهارة رابعة عشرة اسمها `ig-lang` فيها قواعد الكتابة لكل لغة: اللهجة، وصيغة المخاطبة، والأرقام، والعملة.
- طبقة لغوية تحت أدوات بايثون الخمس، فصارت تفهم النص العربي والروسي والتركي والبولندي والتشيكي بدل أن لا ترى فيه أي كلمة.

**لا يُنشر أي شيء دون موافقتك.** المهارات تكتب، وأنت تنشر.

## اللغات المدعومة

| الرمز | اللغة | ما تفهمه الأدوات |
|---|---|---|
| en | الإنجليزية | الفحوصات الأصلية دون أي تغيير |
| ar | العربية | العراقية والخليجية والشامية والمصرية والفصحى، النص من اليمين لليسار، السوابق (و، ف، ب، ل، ال)، الأرقام ٠-٩، أسماء الماركات المكتوبة بحروف لاتينية مثل GRASS |
| ru | الروسية | جذور الكلمات المصرّفة، ё/е، الشَّرطة وعلامات «» |
| tr | التركية | اللواحق، حرف i المنقوط وغير المنقوط، كتابة النسبة %80 |
| pl | البولندية | الجذور المصرّفة، علامات „…” |
| cs | التشيكية | الجذور المصرّفة، علامات „…“، و jsem/jsme كضمير متكلم |

كل أداة تكتشف لغة النص بنفسها، أو تحدّدها أنت بـ `--lang`.

## التثبيت

في تطبيق Claude: أضفها كـ plugin من هذا المستودع.

في Claude Code:

```
/plugin install babili-instagram-agent --marketplace ma-91-02/babili-instagram-agent-multilingual
```

في الإصدارات الأقدم من Claude Code أضف المتجر أولاً:

```
/plugin marketplace add ma-91-02/babili-instagram-agent-multilingual
/plugin install babili-instagram-agent
```

أو يدوياً:

```bash
git clone https://github.com/ma-91-02/babili-instagram-agent-multilingual.git
cp -r babili-instagram-agent-multilingual/skills/ig-* ~/.claude/skills/
```

احتفظ بمجلد `ig-lang` بجانب بقية المجلدات، فالأدوات تبحث عنه هناك.

## أول خطوة: ملف الصوت

انسخ `templates/voice.md` إلى `~/.claude/instagram/voice.md` واملأه، أو أرسل لـ Claude ثلاثة من ريلزك وقل له «اكتب ملف voice.md من هذه». أهم ما فيه قسم **Language**:

- `language: ar-IQ` مثلاً للجمهور العراقي.
- لهجة الريلز المنطوقة، ولغة الكابشن (عامية أو فصحى، لكن لا تخلطهما في منشور واحد).
- صيغة المخاطبة: انت، انتي، أو انتو (الجمع يخاطب الجميع دون افتراض جنس المتابع).
- الأرقام: 0-9 أو ٠-٩، والعملة كما تكتبها: 25,000 دينار.

## أمثلة

```bash
# تقييم الـ hooks
python3 skills/ig-reel/hookscore.py --hook "محد يكلك إن الطباخ يخرب بعد 6 أشهر"

# توقيت سكربت الريل (السرعة الافتراضية للعربية 135 كلمة بالدقيقة)
python3 skills/ig-reel/beats.py script.txt --target 30

# فحص الكابشن: أول 125 حرفاً، حد الهاشتاغات الخمسة، الدعوة للتفاعل
python3 skills/ig-caption/caption.py caption.txt --keywords "منظف مطبخ،إزالة الدهون"

# تنظيف النص من عبارات الذكاء الاصطناعي المستهلكة
python3 skills/ig-human/humanize.py draft.txt --report
```

مثال حقيقي من الاختبارات:

| الـ hook | التقييم |
|---|---|
| محد يكلك إن أغلب منظفات المطبخ تخرب الطباخ بعد 6 أشهر | 85.7 قوي |
| خسرت 200 ألف دينار بسبب منظف واحد | 84.4 قوي |
| مرحبا يا جماعة اليوم راح نحچي عن التنظيف | 0.0 ضعيف: تحية + مقدمة فيديو |

## ما الذي تغيّر عن الأصل

- **المسار الإنجليزي لم يتغير.** الاختبارات تتأكد أن نتائج الأمثلة الأصلية بقيت كما هي (85.6، 81.4، 54.4، 9.6).
- **الإيموجي سليمة.** الأداة الأصلية كانت تحذف الرابط الخفي داخل الإيموجي المركّبة، فتتفكك 👨‍👩‍👧 إلى ثلاثة وجوه. الآن تبقى كما هي.
- **اتجاه النص العربي سليم.** علامات الاتجاه التي تضبط موضع كلمة لاتينية أو رقم داخل جملة عربية لم تعد تُحذف.
- **الهاشتاغات العربية تُحسب.** كان الكابشن الذي فيه ستة هاشتاغات عربية ينجح في فحص الحد الأقصى (خمسة)، لأن الأداة لم تكن تراها أصلاً.

## الحدود بصراحة

عتبات اللغة الإنجليزية قاسها المؤلف الأصلي على 74 hook حقيقياً. أما قوائم العربية والروسية والتركية والبولندية والتشيكية فصيغت بمساعدة Claude وتم التحقق منها على أمثلة الاختبارات، ولم تُقَس على مجموعة حقيقية من الريلز، ولم يراجعها بعد مسوّقون من أهل كل لغة. هي تكشف التحية والمقدمات والعبارات المستهلكة وغياب الأرقام بشكل موثوق، لكنها لا تتنبأ بالريل الناجح، ولا أي أداة تقرأ النص تستطيع ذلك. ثق برسم الاحتفاظ بالمشاهدين أكثر منها.

في اللغات المصرّفة، كثير من الكلمات المستهلكة **يُشار إليها ولا تُستبدل تلقائياً**، لأن الكلمة البديلة الصحيحة تعتمد على الجملة.

## المساهمة

القوائم في `skills/ig-lang/lang/<code>.json` قابلة للتعديل بالكامل. شغّل الاختبارات بعد أي تعديل:

```bash
python3 tests/run_tests.py
```
